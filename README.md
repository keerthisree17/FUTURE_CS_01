# Cyber Security Internship - Task 1

## Vulnerability Assessment Report for a Live Website

**Internship Organization:** Future Interns  
**Domain:** Cyber Security  
**Task Number:** 01  
**Repository:** FUTURE_CS_01

## Project Objective
To assess common web security vulnerabilities, classify identified risks and recommend appropriate remediation measures.

## Tools Used
- Nmap
- OWASP ZAP (Passive Scanning)
- Browser Developer Tools
- Canva

## Project Structure
- Evidence: Screenshots and assessment evidence.
- Report: Final Vulnerability Assessment Report.
- Documentation: Assessment methodology and supporting documentation.

## Assessment Scope
The assessment will focus on passive security observations and authorized vulnerability checks.

## Findings
Assessment findings will be documented after testing.

## Recommendations
Security recommendations will be provided based on verified findings.

## Disclaimer
This project is prepared for educational purposes as part of the Future Interns Cyber Security Internship.
